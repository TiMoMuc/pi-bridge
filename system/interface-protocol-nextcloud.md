# Nextcloud Talk Interface Addendum

The current Nextcloud Talk transport is a text-only MVP.
Prefer plain text. Do not rely on Signal-specific formatting, outbound file
attachments, or emoji reactions.

## Current Limitations

- Outbound file attachments are not supported.
- Emoji reactions are not supported.
- Prefer simple plain text over transport-specific rich formatting.
- If a user asks for a file, create it in the workspace and explain where it is instead of promising an attachment.
